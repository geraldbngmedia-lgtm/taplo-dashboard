## Goal

Build the live interview question panel: a tall, narrow (320px) side panel with three clearly encoded question states and a coral cue box on the active question. Taplo auto-detects answered questions from the audio, so coverage arrives out of order. The panel must show state without implying sequence, and must be readable in peripheral vision.

## Structure

```text
┌─────────────────────────────┐
│ INTERVIEW            ● ● ●  │  window chrome
├─────────────────────────────┤
│ BACKGROUND          [3 Qs]  │  section header + hairline
│  ●  Could you walk me...    │  covered, green dot, dimmed
│  ●  ┌───────────────────┐   │  active, coral dot
│     │ What specific...  │   │  raised white card + shadow
│     │ 💡 Listen for...  │   │  coral-tinted cue box
│     └───────────────────┘   │
│  ○  How do you handle...    │  not covered, hollow dot
│                             │
│ QUALIFICATIONS              │
│  ○  Are you comfortable...  │
├─────────────────────────────┤
│ ● LIVE CAPTURE ACTIVE v1.4.2│  footer
└─────────────────────────────┘
```

**No vertical rail.** The dots float beside each question with no connecting line. A top-to-bottom rail would falsely imply the interview marches down the list in order, and it does not. Dots alone carry state.

## Details

**Chrome.** "INTERVIEW" in 10px uppercase, +0.18em tracking, tertiary ink. Three 9px traffic-light dots on the right, muted so they read as chrome, not signal.

**Section headers.** 10px uppercase tertiary ink with a hairline divider underneath. BACKGROUND carries a count pill on the right ("3 Qs"): sunken background, 9px, tertiary ink, fully rounded.

**States.**
- *Covered* (green dot): detected automatically or set by the recruiter. Filled green dot, question text dimmed to 45% ink. Never struck through. Can appear on any question at any time, in any order.
- *Active* (coral dot): the question being asked right now. Filled coral dot, question lifted into a white card with a soft shadow and full-weight charcoal text. Inside, a coral-wash cue box with a lightbulb icon and the coaching line. Exactly one active at a time.
- *Not covered* (hollow grey dot): 1.5px border, transparent fill, text at 45% ink.

**Auto-complete pulse.** When a question flips to covered, over ~600ms the dot scales up slightly and settles back while cross-fading grey to green, with a soft expanding ring that fades out behind it. The question text eases from full ink to dimmed over the same window. Calm, single-shot, no loop. The point is peripheral-vision legibility: a recruiter looking at the candidate still notices Taplo picked something up. Respects `prefers-reduced-motion` by falling back to a plain cross-fade.

**Preview demo.** On mount, after ~3 seconds, "How do you handle conflict in high-pressure technical environments?" auto-flips from not covered to covered with the pulse, even though it sits below the active question. This demonstrates out-of-order detection. The demo timer is a prop-gated preview affordance, off by default in real use.

**Footer.** Small green dot plus "LIVE CAPTURE ACTIVE" in 9px uppercase tertiary ink on the left, "v1.4.2" on the right, separated by a hairline.

**Scroll.** The question list scrolls; chrome and footer stay fixed. Thin, low-contrast scrollbar.

Copy uses commas and periods only, no dashes.

## Technical notes

- New component `src/components/capture/LiveQuestionPanel.tsx`, driven by sections of `{ id, title, count?, questions: { id, text, state, cue? }[] }` with `state: "covered" | "active" | "upcoming"`. Sample content ships as a fixture in `src/lib/question-fixtures.ts` so the panel renders standalone.
- Pulse implemented with a `@keyframes taplo-dot-pulse` plus `taplo-ring` in `src/styles.css`, triggered by a per-question `justCovered` flag the component sets when a state transitions into `covered`, cleared after the animation. Both wrapped so reduced-motion collapses them.
- Colours from existing tokens (`--surface-card`, `--hairline`, `--ink`, `--ink-tertiary`, `--accent`, `--accent-wash`), plus two new tokens: `--state-covered` (calm green) and `--panel-shadow-card`. The panel scopes a warmer `--surface-page` of `#F0EBE2` locally. No hardcoded hex in the component.
- Thin scrollbar via a `@utility scroll-quiet` rule in `src/styles.css`.
- Lightbulb icon from `lucide-react`.
- Build fix carried over from the mockup: no rail means the trailing-line stub issue disappears entirely.
- The panel is presentational. Wiring it into `CapturePanel` and mapping live detection onto these states is a follow up.
